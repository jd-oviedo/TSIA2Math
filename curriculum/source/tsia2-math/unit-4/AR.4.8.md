#### **Part 1: Guided Notes**

##### A Square Root Comes Out Only If It Is a Perfect Square

Simplifying a radical means pulling out whatever has an exact square root and leaving the rest inside.

$$\sqrt{48}$$

Step 1: Find the **largest** perfect square that divides $48$. The perfect squares are $4, 9, 16, 25, 36, 49$. Of these, $16$ divides $48$.

Step 2: Split the radicand into that factor and what is left. $48 = 16 \times 3$.

$$\sqrt{48} = \sqrt{16 \times 3} = \sqrt{16} \times \sqrt{3}$$

Step 3: Take the root of the perfect square. $\sqrt{16} = 4$.

$$4\sqrt{3}$$

**The number that comes out is the root, not the factor.** $\sqrt{16}$ leaves as $4$, never as $16$. That sounds obvious written down and is one of the two commonest errors in this topic.

##### Take the Largest Perfect Square, Not the First One

$4$ also divides $48$, and $48 = 4 \times 12$. That gives:

$$\sqrt{48} = 2\sqrt{12}$$

This is **correct arithmetic and an unfinished answer**, because $12$ still contains a perfect square. Keep going and $\sqrt{12} = 2\sqrt{3}$, so $2\sqrt{12} = 4\sqrt{3}$, the same place you would have reached in one step.

**Check whether the number left inside still has a square factor.** If it does, you are not finished. A radicand of $2, 3, 5, 6, 7, 10, 11, 13, 14, 15$ is finished. A radicand of $8, 12, 18, 20, 27, 32, 45, 50$ is not.

##### Adding: Only Like Radicals Combine

$$3\sqrt{5} + 2\sqrt{5} = 5\sqrt{5}$$

Three of something plus two of that same something is five of them. The $\sqrt{5}$ is the thing being counted, exactly like a variable, and it does not change.

**The radicands are not added.** $3\sqrt{5} + 2\sqrt{5}$ is not $5\sqrt{10}$.

Check with a calculator-free estimate. $\sqrt{5}$ is a bit over $2$, so the left side is about $5 \times 2.2 = 11$. Meanwhile $5\sqrt{10}$ is about $5 \times 3.2 = 16$. Different numbers.

Unlike radicands never combine at all:

$$3\sqrt{5} + 2\sqrt{7} \quad\text{stays}\quad 3\sqrt{5} + 2\sqrt{7}$$

##### The Mistake That Costs the Most Points

**Splitting a root across a sum.**

$$\sqrt{9 + 16} \quad\text{written as}\quad \sqrt{9} + \sqrt{16} = 3 + 4 = 7$$

The real value is $\sqrt{25} = 5$. Seven is not five.

**A square root splits across multiplication and division. It does not split across addition or subtraction.**

$$\sqrt{a \times b} = \sqrt{a} \times \sqrt{b} \quad\text{(true)}$$

$$\sqrt{a + b} \neq \sqrt{a} + \sqrt{b} \quad\text{(false)}$$

**Why it happens:** every other operation you have met distributes, so the hand does it automatically. The radical is the exception, and nothing on the page marks it as one.

**The fix is one numerical check you can do in your head.** Try the rule on $9$ and $16$, where both roots are whole numbers. If the rule were true, $\sqrt{25}$ would equal $7$. It does not. That single example is enough to kill the move every time you are tempted by it.

##### Multiplying: The Radicands Do Combine

$$\sqrt{2} \times \sqrt{8} = \sqrt{16} = 4$$

Under multiplication the radicands genuinely multiply, which is the rule that **is** true. Multiply what is inside, then simplify what comes out.

$$\sqrt{6} \times \sqrt{10} = \sqrt{60} = \sqrt{4 \times 15} = 2\sqrt{15}$$

Notice the second step. $\sqrt{60}$ is a correct answer to the multiplication and not a finished one, because $60$ still contains the perfect square $4$.

**So multiplication has two steps, not one.** Combine, then simplify.

##### Rationalising: Clear the Radical Off the Bottom

A finished answer does not have a radical in the denominator.

$$\frac{6}{\sqrt{3}}$$

Step 1: Multiply the top **and** the bottom by $\sqrt{3}$. Multiplying by $\frac{\sqrt{3}}{\sqrt{3}}$ is multiplying by $1$, so the value does not change.

$$\frac{6}{\sqrt{3}} \times \frac{\sqrt{3}}{\sqrt{3}} = \frac{6\sqrt{3}}{3}$$

Step 2: The bottom is now $\sqrt{3} \times \sqrt{3} = 3$, an ordinary number.

Step 3: Reduce. $\frac{6}{3} = 2$.

$$2\sqrt{3}$$

**Both halves get multiplied.** Multiplying only the numerator changes the value of the fraction and leaves the radical downstairs anyway, so it fails twice over.

##### The Five Traps

1. **Splitting a root across a sum.** $\sqrt{9 + 16} = 5$, not $7$. Roots split across multiplication only.
2. **Moving a perfect square out without rooting it.** $\sqrt{16 \times 3}$ gives $4\sqrt{3}$, not $16\sqrt{3}$.
3. **Extracting a perfect square that is not the largest.** $2\sqrt{12}$ is correct but unfinished. Check whether the radicand still has a square factor.
4. **Adding the radicands when adding like radicals.** $3\sqrt{5} + 2\sqrt{5} = 5\sqrt{5}$, not $5\sqrt{10}$.
5. **Rationalising only the numerator.** Multiply top and bottom by the same thing, or the value changes.
