Algebraic expressions are like puzzles waiting to be solved, and simplifying or evaluating them is all about organizing the pieces correctly.

This lesson will focus on two key skills: **combining like terms** and **substituting values into expressions**.

Mastering these will help you tackle more complex problems later in Algebra 1. Let’s dive in!

---

### **Combining Like Terms**

In Algebra, you’ll often see expressions with multiple terms. To simplify them, you need to combine terms that are alike.

#### **What Are Like Terms?**

* **Like terms** have the **same variable raised to the same power**.
  + Example: $3x$ and $5x$ are like terms because they both have $x^1$.
  + $2x^2$ and $4x$ are **not** like terms because their variables are raised to different powers.
* **Constants** (numbers without variables) are also considered like terms.

#### **How to Combine Like Terms:**

1. Add or subtract the coefficients (the numbers in front of the variables).
2. Keep the variable part the same.

#### **Example 1: Simplify $4x + 7x$:**

* Combine the coefficients: $4 + 7 = 11$.
* The simplified expression is $11x$.

#### **Example 2: Simplify $3x + 2y - x + 5y + 4$:**

* Combine the $x$-terms: $3x - x = 2x$.
* Combine the $y$-terms: $2y + 5y = 7y$.
* The constant $4$ stays the same.
* The simplified expression is $2x + 7y + 4$.

---

### **Substituting Values into Expressions**

Once you simplify an expression, you can evaluate it by substituting values for the variables.

#### **Steps for Substitution:**

1. Replace each variable in the expression with the given number.
2. Use the order of operations (PEMDAS) to calculate the result.

#### **Example 1: Evaluate $3x + 2$ when $x = 4$:**

* Substitute $x = 4$: $3(4) + 2$.
* Multiply first: $12 + 2 = 14$.
* The answer is $14$.

#### **Example 2: Evaluate $2a + 3b - 4$ when $a = 3$ and $b = 5$:**

* Substitute $a = 3$ and $b = 5$: $2(3) + 3(5) - 4$.
* Multiply first: $6 + 15 - 4$.
* Add and subtract: $21 - 4 = 17$.
* The answer is $17$.

---

### **Why Are These Skills Important?**

* **Simplifying expressions** makes equations easier to solve.
* **Substituting values** helps you apply Algebra to real-world situations, like calculating total costs or predicting outcomes.

---

### **Tips for Success**

1. **Highlight like terms.** Use different colors to group terms with the same variable or power.
2. **Double-check substitutions.** Make sure you replace every variable with its correct value.
3. **Work step by step.** Simplify the expression first before substituting values to avoid mistakes.
4. **Practice regularly.** The more you practice, the faster and more accurate you’ll become.

### **Challenge Problem**

Simplify $6x + 4y - 2x + 8 - 3y + 5$ and then evaluate it for $x = 2$ and $y = 1$.

#### **Step 1: Simplify**

* Combine $x$-terms: $6x - 2x = 4x$.
* Combine $y$-terms: $4y - 3y = y$.
* Combine constants: $8 + 5 = 13$.
* Simplified expression: $4x + y + 13$.

#### **Step 2: Substitute**

* Substitute $x = 2$ and $y = 1$: $4(2) + 1 + 13$.
* Multiply and add: $8 + 1 + 13 = 22$.
* Answer: $22$.
