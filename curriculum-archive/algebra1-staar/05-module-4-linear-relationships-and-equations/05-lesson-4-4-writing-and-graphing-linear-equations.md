# **Lesson 4.3: Writing and Graphing Linear Equations**

### **Why Should You Care About Writing and Graphing Linear Equations?**

Imagine you’re designing a skateboard ramp, predicting profits for a business, or tracking your progress in the gym. All of these involve relationships between variables, and linear equations help you **model, predict, and analyze** these relationships.

In this lesson, you’ll learn how to **write linear equations from different sources** (like tables, graphs, and word problems) and **graph them using various methods**. By the end, you’ll be able to take a set of data or a real-world scenario and turn it into an equation you can use!

---

## **1. Writing Equations from Tables, Graphs, and Word Problems**

A linear equation describes a **consistent** relationship between two variables. The key is recognizing **patterns** in numbers, graphs, and word problems to find the equation.

### **(A) Writing Equations from Tables**

A table shows input (x-values) and output (y-values). If the change in $x$ results in a consistent change in $y$, it’s **linear**!

🔹 **Example:**

| $x$ | $y$ |
| --- | --- |
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |
| 4 | 9 |

Notice that as $x$ increases by 1, $y$ increases by 2. That means the **slope** ($m$) is **2**.

Now, using the slope-intercept form:

$y = mx + b$

We substitute $m = 2$. To find $b$, use any point, like $(1,3)$:

$3 = 2(1) + b$ $b = 1$

So, the equation is **$y = 2x + 1$**.

📌 **When to Use This:**

* When you have a pattern of numbers
* When you need to find a trend from data

---

### **(B) Writing Equations from Graphs**

A graph of a linear equation is always a **straight line**. To write the equation:

1. **Find the slope ($m$)**

   * Pick two points on the line: $(x\_1, y\_1)$ and $(x\_2, y\_2)$.
   * Use the formula: $m = \frac{y\_2 - y\_1}{x\_2 - x\_1}$
2. **Find the y-intercept ($b$)**

   * Look at where the line crosses the **y-axis** (this is $b$).
3. **Write the equation in $y = mx + b$ form.**

🔹 **Example:** A line passes through $(2, 4)$ and $(5, 10)$.

1. Find the slope: $m = \frac{10 - 4}{5 - 2} = \frac{6}{3} = 2$
2. Find the y-intercept: Use $y = mx + b$ and substitute $(2,4)$: $4 = 2(2) + b$ $b = 0$
3. The equation is **$y = 2x$**.

📌 **When to Use This:**

* When you have a **graph of a line** and need to find its equation

---

### **(C) Writing Equations from Word Problems**

Word problems describe relationships between two quantities. The key is translating words into **math**!

🔹 **Example:** A gym charges a $25 membership fee plus $10 per session. Write an equation for the total cost $C$ based on the number of sessions $x$.

* The **starting fee** (y-intercept) is **$25** → **$b = 25$**
* The **rate of change** (slope) is **$10 per session** → **$m = 10$**
* The equation is **$C = 10x + 25$**

📌 **When to Use This:**

* When solving **real-life problems** involving cost, motion, and trends

---

## **2. Graphing Linear Equations Using Various Methods**

There are **three main ways** to graph a linear equation:

### **(A) Using a Table of Values**

1. Pick several values for $x$.
2. Plug them into the equation to find $y$.
3. Plot the points and connect them with a **straight line**.

🔹 **Example:** Graph $y = 2x - 3$.

| $x$ | $y$ |
| --- | --- |
| -1 | -5 |
| 0 | -3 |
| 1 | -1 |
| 2 | 1 |

Plot these points and draw the line!

📌 **When to Use This:**

* When you’re unsure about the equation’s shape

---

### **(B) Using Slope and Y-Intercept (Slope-Intercept Form: $y = mx + b$)**

1. **Plot the y-intercept** ($b$).
2. **Use the slope** ($m$) to find another point.
   * Rise over run: If $m = \frac{3}{2}$, go **up 3** and **right 2**.
3. **Draw the line through the points.**

📌 **When to Use This:**

* When you already have the equation in **$y = mx + b$** form

---

### **(C) Using Intercepts (Standard Form: $Ax + By = C$)**

1. **Find the x-intercept:** Set $y = 0$ and solve for $x$.
2. **Find the y-intercept:** Set $x = 0$ and solve for $y$.
3. **Plot both points and draw the line.**

🔹 **Example:** Graph $3x + 4y = 12$.

* **X-intercept:** $3x + 4(0) = 12 \Rightarrow x = 4$ → Point: $(4,0)$
* **Y-intercept:** $3(0) + 4y = 12 \Rightarrow y = 3$ → Point: $(0,3)$

📌 **When to Use This:**

* When the equation is in **Standard Form**

---

## **3. Helpful Hints for Success** 🎯

✅ **Memorize the forms of linear equations.** Knowing **slope-intercept**, **point-slope**, and **standard form** makes things easier.

✅ **Always find the slope first.** Whether using a **table**, **graph**, or **word problem**, knowing $m$ helps you write the equation quickly.

✅ **Use different methods to graph.** Pick the **fastest** method for the equation you’re given.

✅ **Check your work.** If a point is on your graph, it should satisfy the equation!

By mastering **writing and graphing linear equations**, you’ll have a solid foundation for **understanding relationships, solving real-world problems, and predicting trends**. Keep practicing, and soon this will be second nature! 🚀
