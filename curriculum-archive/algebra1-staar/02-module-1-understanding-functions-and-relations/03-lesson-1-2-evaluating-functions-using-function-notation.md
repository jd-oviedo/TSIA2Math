## **Why Should You Care About Function Notation?**

Imagine you’re using a music streaming app. You type in an artist’s name, and the app generates a playlist for you. This is like a function: you **input** the artist, and the app **outputs** a playlist. Function notation helps us **organize and evaluate functions efficiently**, just like your favorite apps process data!

By the end of this lesson, you’ll be able to **understand function notation, evaluate functions, and interpret function behavior from graphs**—essential for algebra, data analysis, and problem-solving!

---

## **Understanding Function Notation**

Function notation is just a fancy way of writing equations. Instead of using **$y$**, we use **$f(x)$** to represent a function.

### **Traditional Equation:**

![LaTeX: y=2x+5](https://k12.instructure.com/equation_images/y%253D2x%252B5?scale=1 "y=2x+5")

### **Function Notation:**

![LaTeX: f\left(x\right)=2x+5](https://k12.instructure.com/equation_images/f%255Cleft(x%255Cright)%253D2x%252B5?scale=1 "f\left(x\right)=2x+5")

Both mean the same thing! **$f(x)$ is just another name for $y$, the output of the function.**

📌 **Key Tip:** The letter **$f$** is just a name for the function—you could use $g(x)$, $h(x)$, or any other letter!

---

## **Evaluating Functions**

When you see something like $f(3)$, it means:  
✅ Plug **$x = 3$** into the function  
✅ Solve to find the **output (y-value)**

### **Example:**

If $f(x) = 2x + 5$, find $f(3)$.

**Step 1:** Replace $x$ with 3.

![LaTeX: f\left(3\right)=2\left(3\right)+5](https://k12.instructure.com/equation_images/f%255Cleft(3%255Cright)%253D2%255Cleft(3%255Cright)%252B5?scale=1 "f\left(3\right)=2\left(3\right)+5")

**Step 2:** Solve.

![LaTeX: f\left(2\right)=6+5=11](https://k12.instructure.com/equation_images/f%255Cleft(2%255Cright)%253D6%252B5%253D11?scale=1 "f\left(2\right)=6+5=11")

📌 **What does this mean?** When $x = 3$, the function outputs **11**.

## **Function Behavior from Graphs**

Graphs tell us **how a function behaves**—whether it increases, decreases, or stays constant.

### **Increasing vs. Decreasing Functions**

* **Increasing Function** 📈 → As $x$ increases, $y$ also increases.
* **Decreasing Function** 📉 → As $x$ increases, $y$ decreases.

### **Example:**

Look at the graph below:

|  |  |
| --- | --- |
| LaTeX: x | LaTeX: f\left(x\right) |
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |
| 4 | 8 |

Since $f(x)$ is getting bigger as $x$ increases, the function is **increasing**.

📌 **Key Tip:** Functions don’t have to increase forever! They can go **up and down** at different parts of the graph.

---

## **Understanding Key Function Behavior**

### **(A) Maximum and Minimum Points**

* **Maximum** → The highest point of a function (think of a mountain peak).
* **Minimum** → The lowest point of a function (like a valley).

### **(B) Intercepts (Where Functions Cross Axes)**

* **$x$-intercept** → Where the function crosses the $x$-axis (when $f(x) = 0$).
* **$y$-intercept** → Where the function crosses the $y$-axis (when $x = 0$).

**Example:** If a function has a **maximum at (2, 7)**, it means at $x = 2$, the highest point is **7**.

📌 **Key Tip:** In real life, maximums and minimums help **optimize** things, like finding the highest profit or lowest cost!

## **Real-World Applications of Function Notation**

### **(A) Business & Economics 💰**

A company’s profit function might be:

$P(x) = 50x - 200$

where $x$ is the number of products sold, and $P(x)$ is the profit.

If you sell **10 items**, find the profit:

$P(10) = 50(10) - 200 = 500 - 200 = 300$

So, the company makes **$300** in profit!

---

### **(B) Temperature Conversions 🌡️**

If the function for Celsius to Fahrenheit is:

$F(C) = \frac{9}{5}C + 32$

Find $F(20)$ (convert 20°C to Fahrenheit):

$F(20) = \frac{9}{5}(20) + 32 = 36 + 32 = 68$

So, **20°C is 68°F**!

📌 **Key Tip:** Function notation helps in **science, economics, and everyday life!**
