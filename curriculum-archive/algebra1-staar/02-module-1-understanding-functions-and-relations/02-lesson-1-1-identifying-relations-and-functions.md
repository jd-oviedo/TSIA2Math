## **Why Do We Need to Understand Functions?**

Imagine you’re ordering food delivery. You enter your address, and the app tells you exactly how much the total cost will be, including tax and fees. That’s a **function** in action—it takes an input (your order) and gives you one unique output (the final price).

By the end of this lesson, you’ll be able to **understand domain and range** and **identify functions from graphs, tables, and equations**—essential skills for algebra and beyond!

---

## **What Are Relations and Functions?**

A **relation** is just a set of ordered pairs ($x, y$). It shows a connection between inputs (x-values) and outputs (y-values).

A **function** is a special type of relation where **each input has exactly one output**—no duplicates allowed for $x$!

✅ **Function:** $(1, 3), (2, 5), (3, 7)$ → Every $x$-value is unique!  
❌ **Not a Function:** $(1, 3), (1, 5), (2, 4)$ → The input $x = 1$ has two different outputs!

📌 **Key Tip:** If an $x$-value is repeated with different $y$-values, **it’s NOT a function.**

---

## **Recognizing Functions from Different Representations**

Functions can be shown in **graphs, tables, and equations.** Let’s break it down!

### **(A) Identifying Functions from Graphs**

The easiest way to check if a graph is a function is by using the **Vertical Line Test**:

✅ **If a vertical line touches the graph at only ONE point at a time, it’s a function.**  
❌ **If a vertical line touches at multiple points, it’s NOT a function.**

**Example:**

* A straight line? ✅ Function!
* A sideways parabola? ❌ Not a function!

📌 **Key Tip:** Always imagine drawing vertical lines to check for functions.

---

### **(B) Identifying Functions from Tables**

A table lists inputs and outputs. To be a function, **each input (x-value) must pair with exactly one output (y-value).**

✅ **Function:**

|  |  |
| --- | --- |
| **x** | **y** |
| 1 | 4 |
| 2 | 5 |
| 3 | 6 |

Each $x$ has only **one** $y$, so it’s a function!

❌ **Not a Function:**

|  |  |
| --- | --- |
| **x** | **y** |
| 1 | 4 |
| 1 | 7 |
| 2 | 5 |

Since $x = 1$ has two different outputs, this is **not a function**.

📌 **Key Tip:** If an x-value repeats with different y-values, **it’s NOT a function!**

---

### **(C) Identifying Functions from Equations**

A function is a rule where **every x-value gives exactly one y-value.**

Common function equations:  
✅ **$y = 2x + 3$** (Linear Function – Always a function)  
✅ **$y = x^2 - 4$** (Quadratic Function – Always a function)  
❌ **$x = y^2$** (Not a function – fails Vertical Line Test)

📌 **Key Tip:** If you can solve for $y$ and get just **one value** for each $x$, it’s a function!

---

### **(D) The Vertical Line Test (for Graphs)**

Ever looked at a graph and wondered, “Is this a function?” The **vertical line test** makes it super easy.

Here’s how it works:

* **Imagine (or draw) vertical lines** (lines that go straight up and down) all across the graph.
* If **any** vertical line touches the graph **more than once**, then it’s **NOT a function**.
* If **no** vertical line touches the graph more than once, it **IS a function**.

---

### 🔑 Why it works:

A function can only have **one output (y-value)** for each **input (x-value)**. If a vertical line hits two or more points on the graph, that means a single x-value is giving you more than one y-value—uh-oh, that breaks the rule!

---

### 🧠 Quick Example:

(Insert Graph Image 1: A straight diagonal line – passes the test)  
✅ This is a function! Every vertical line touches only once.

(Insert Graph Image 2: A sideways parabola – fails the test)  
❌ Not a function. Some vertical lines hit the graph twice.

📌 **Pro Tip:** You don’t have to draw the lines—just imagine them. If you can *see* a place where a vertical line would hit twice, it fails the test.

---

### **(E) Mapping Diagrams**

A **mapping diagram** shows how each input (x) connects to an output (y). Think of it like a flow chart that matches numbers from one group to another.

You’ll usually see two ovals:

* One for **inputs (domain)**
* One for **outputs (range)**  
  And arrows pointing from input values to output values.

---

### 🧠 How to use it:

* If an **input has more than one arrow** pointing to different outputs, it’s **NOT a function**.
* If each input connects to **only one output**, you’re good—it **IS a function**.

---

### 🧪 Example:

(Insert Mapping Diagram Image 1: 1 → 2, 2 → 4, 3 → 6)  
✅ Function – every input goes to one output.

(Insert Mapping Diagram Image 2: 1 → 2 and 1 → 3)  
❌ Not a function – input "1" goes to **two outputs**.

📌 **Helpful Hint:** Mapping diagrams are great for visual learners! Use them to double-check your understanding of inputs and outputs.

---

## ✏️ Equations: Are They Functions?

Sometimes, you’ll see a relation written as an **equation**. You can still figure out if it’s a function!

Ask yourself this:  
➡️ “Does every x-value give me **exactly one y-value** when I solve the equation?”

---

### ✅ Common Function Equations:

* `y = 2x + 1` ← Linear → **Function**
* `y = x² – 3` ← Quadratic → **Function**

These are functions because no matter what x you plug in, you’ll get just one y out.

---

### ❌ Not a Function:

* `x = y²`

This one’s tricky! When you try solving for y, you’ll get two answers (a positive and a negative). That means **one x leads to two y’s**, so it’s **not a function**.

📌 **Shortcut:** If solving the equation for y gives **two outputs**, it’s not a function. Boom.

---

## 🏁 Wrapping It All Up

You’ve now got FIVE new tools to test if a relation is a function:

| Method | What to Look For | Function or Not? |
| --- | --- | --- |
| **Ordered Pairs** | Every x-value is unique | ✅ Function |
| **Table** | Each input is paired with one output | ✅ Function |
| **Graph** | Vertical line hits once | ✅ Function |
| **Mapping Diagram** | Each input points to one output | ✅ Function |
| **Equation** | Each x gives ONE y | ✅ Function |

## **Real-World Applications of Functions**

Functions help us **predict outcomes and make decisions** in everyday life!

### **(A) Temperature Conversions 🌡️**

The formula to convert Fahrenheit to Celsius is:

$C = \frac{5}{9} (F - 32)$

This is a **function** because each Fahrenheit temperature has exactly **one** Celsius value!

### **(B) Online Shopping 🛒**

When you order online, the total cost is based on:

$\text{Total} = \text{price per item} \times \text{quantity} + \text{tax}$

This is a **function**—each order amount gives only **one** final cost!

---

## **Key Steps for Success 🎯**

✅ **Remember:** A function means each input (x) has only one output (y).  
✅ **Use the Vertical Line Test** for graphs.  
✅ **Check for repeating x-values** in tables—if they repeat with different outputs, it’s NOT a function!  
✅ **Solve for $y$** in equations—if there’s more than one $y$-value for an $x$, it’s NOT a function.

---

Functions are **everywhere** in math and real life! Whether it’s tracking money, measuring temperature, or ordering food, functions help us understand **cause-and-effect relationships**.

Keep practicing, and soon you’ll **spot functions easily!** 🔥
