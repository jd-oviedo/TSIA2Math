## **Introduction to Functions**

Welcome to **Module 1: Introduction to Functions**—the launchpad for understanding one of the most important concepts in Algebra 1!

In this module, you’ll build a solid foundation for understanding how functions work. You’ll explore how inputs and outputs are related, learn how to write and evaluate functions using proper notation, and practice reading functions from graphs and tables. By the end of this module, you’ll be able to confidently identify functions and describe how they behave using different formats.

Whether you’re working with a set of points, a table, or a graph, this module will help you recognize patterns and understand how math models real-world relationships.

---

### **What You’ll Learn in This Module:**

#### **Lesson 1.1: Identifying Relations and Functions**

* Understand the difference between a relation and a function.
* Use mapping diagrams, sets of ordered pairs, tables, and graphs to determine if a relation is a function.
* Learn what makes a function valid—every input (x) must have exactly one output (y).
* Get comfortable with function vocabulary: domain, range, input, output.

#### **Lesson 1.2: Evaluating Functions Using Function Notation**

* Learn how to read and interpret function notation like f(x).
* Substitute values into a function to evaluate it—think of f(x) as a rule or a machine!
* Apply function notation to solve real-world problems.
* Understand the importance of precision when using notation.

#### **Lesson 1.3: Interpreting Graphs and Tables of Functions**

* Use graphs and tables to describe how a function behaves.
* Identify key features of functions like increasing or decreasing intervals, x- and y-intercepts, and trends in the data.
* Match visual representations with real-world situations.
* Practice making sense of what a function is doing just by looking at a picture or a chart.

---

### **Why This Module Matters:**

Functions are everywhere in Algebra 1 and beyond. They help us model real-life scenarios, understand how things are changing, and make predictions. Mastering the basics now will make the rest of the course feel way more manageable.

---

### **Tips for Success:**

* A function pairs each input with only one output—remember the phrase: “x doesn’t cheat!”
* Use highlighters or color-coding when working with graphs or tables to track inputs and outputs.
* When evaluating functions, plug in carefully—mistakes often happen with signs or basic math!
* Connect what you see (a graph or table) to what it means—practice explaining it in your own words.

---

**By the end of this module, you’ll be able to recognize, evaluate, and describe functions like a pro. Let’s get started with Lesson 1.1!**
